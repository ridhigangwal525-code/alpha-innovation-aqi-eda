# 🌍 Urban Air Quality Index (AQI) Exploratory Data Analysis (EDA)

An end-to-end Exploratory Data Analysis project analyzing urban pollution metrics, particulate matter distribution, and temporal trends. Developed as part of the internship assignment at **Alpha Innovation**.

---

## 📊 Project Overview
This project examines real-world air quality data to uncover key insights regarding:
* **Primary Pollutant Drivers:** Identifying which particulate matters (`PM2.5`, `PM10`) drive hazardous AQI spikes.
* **Geospatial Disparities:** Comparing average air quality across major metropolitan regions.
* **Temporal Seasonality:** Visualizing daily and seasonal pollution shifts using time-series models.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python 3.x
* **Libraries:** 
  * `Pandas` (Data manipulation & cleaning)
  * `Matplotlib` (Data visualization & plotting)
  * `NumPy` (Numerical operations)

---

## 🚀 How to Run the Code
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the script: `python aqi_analysis.py`
